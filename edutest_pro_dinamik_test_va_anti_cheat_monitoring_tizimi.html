📘 3 daqiqada bepul Firebase ochish bo'yicha qo'llanma:

  2. Chap menyudan Build > Realtime Database bo'limiga kiring va Create Database bosing.

  4. Hosil bo'lgan https://...firebaseio.com manzilini yuqoridagi maydonga joylang va "Saqlash & Ulanish" tugmasini bosing. Bo'ldi!
